Mechatronics

Ball balancing robot

A complete electromechanical system I designed and built from scratch. This solo project spans mechanical design, PCB design with custom electronics, and real-time control software. I integrated a Raspberry Pi 5 with stepper motor drivers for precise actuation and implemented closed-loop visual control using OpenCV for real-time ball position detection and servo loop compensation.

Overview

This build combines mechanical design, electronics, and control into a single closed-loop system. The core challenge was achieving stable visual tracking and smooth actuation for real-time balancing. Tuning demanded precise, low-latency ball tracking, and the iterative process to stabilize the system took significant experimentation. Designing the PCB was another hurdle since it was my first board. That learning curve was a big reason I took on the project: to gain hands-on experience in end-to-end system design and troubleshooting.

  • Designed the frame, linkage, and electronics as a cohesive system.
  • Built custom PCB and motor driver integration for precise actuation.
  • Implemented OpenCV-based ball detection and feedback control.
  • Deployed on Raspberry Pi 5 with real-time software tuning.
